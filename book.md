# Справочник по методам архитектуры и механик игры «Звёздный Защитник»

В данном руководстве приведен подробный разбор всех основных методов, используемых при разработке аркадного космического шутера **«Звёздный Защитник»**. Разделён на категории: методы игрового цикла, методы сущностей, логика столкновений и спавна, методы работы с коллекциями и графические методы Canvas 2D API.

---

## 1. Методы игрового цикла и архитектуры (Game Loop & Architecture)

### 1.1 `init()`
* **Как работает:** Выполняет первичную настройку игры. Подключает холст (Canvas), инициализирует контекст отрисовки $2D$, привязывает обработчики событий клавиатуры и мыши, устанавливает начальные значения очков и жизней игрока, а также загружает графические и звуковые ресурсы.
* **Что возвращает:** `void` (ничего не возвращает) или `Promise<void>` в случае асинхронной загрузки текстур и звуков.
* **Зачем используется:** Гарантирует подготовку всей рабочей среды и ресурсов до того, как начнется рендеринг кадра или обработка действий пользователя.
* **Пример кода:**
  ```javascript
  async init() {
    this.canvas = document.getElementById('gameCanvas');
    this.ctx = this.canvas.getContext('2d');
    this.bindEvents();
    await this.resourceLoader.loadAll();
    this.reset();
  }
  ```

---

### 1.2 `start()`
* **Как работает:** Запускает бесконечный цикл обновлений и отрисовки с помощью вызова `requestAnimationFrame(loop)`. Записывает метку времени первого кадра для точного расчёта $\Delta t$ (deltaTime).
* **Что возвращает:** `void`
* **Зачем используется:** Служит точкой входа для запуска игрового процесса после завершения инициализации или при выходе из меню паузы.
* **Пример кода:**
  ```javascript
  start() {
    this.isRunning = true;
    this.lastTime = performance.now();
    requestAnimationFrame(this.gameLoop.bind(this));
  }
  ```

---

### 1.3 `update(deltaTime)`
* **Как работает:** Принимает разницу во времени между кадрами $\Delta t$ в секундах. Вызывает методы обновления состояния у каждого активного объекта на экране: смещение корабля игрока, передвижение пуль, позиционирование врагов, снижение таймеров перезарядки и анимации.
* **Что возвращает:** `void`
* **Зачем используется:** Обеспечивает физику и логику игры, независимую от частоты обновления экрана (FPS). Позволяет объектам перемещаться с одинаковой скоростью на $60\text{ Hz}$ и $144\text{ Hz}$ мониторах.
* **Пример кода:**
  ```javascript
  update(deltaTime) {
    if (!this.isRunning) return;
    this.player.update(deltaTime);
    this.bullets.forEach(b => b.update(deltaTime));
    this.enemies.forEach(e => e.update(deltaTime));
    this.checkCollisions();
  }
  ```

---

### 1.4 `render()` / `draw(ctx)`
* **Как работает:** Получает контекст рендеринга `ctx`. Очищает область экрана, затем последовательно отрисовывает фон, звезды, корабль игрока, снаряды, врагов, визуальные эффекты (взрывы) и элементы пользовательского интерфейса (HUD).
* **Что возвращает:** `void`
* **Зачем используется:** Отвечает исключительно за визуальное отображение текущего состояния игрового мира на экран пользователя на каждом кадре.
* **Пример кода:**
  ```javascript
  render(ctx) {
    ctx.clearRect(0, 0, this.width, this.height);
    this.background.draw(ctx);
    this.player.draw(ctx);
    this.enemies.forEach(e => e.draw(ctx));
    this.ui.draw(ctx);
  }
  ```

---

### 1.5 `restart()` / `reset()`
* **Как работает:** Возвращает все глобальные переменные и коллекции в исходное состояние: очищает массивы пуль и врагов, сбрасывает счёт очков $Score = 0$, восстанавливает здоровье игрока до $100\%$ и перемещает корабль в центр нижней части экрана.
* **Что возвращает:** `void`
* **Зачем используется:** Позволяет начать новую игру после поражения (`Game Over`) без полной перезагрузки веб-страницы.
* **Пример кода:**
  ```javascript
  reset() {
    this.score = 0;
    this.player.health = 100;
    this.player.x = this.width / 2;
    this.enemies = [];
    this.bullets = [];
    this.isGameOver = false;
  }
  ```

## 2. Методы сущностей и механик игрока (Entities & Mechanics)

### 2.1 `move(dx, dy, deltaTime)`
* **Как работает:** Прибавляет к текущим координатам объекта вектор смещения с учётом скорости $v$ и времени $\Delta t$: $x_{new} = x + dx \cdot v \cdot \Delta t$. Также ограничивает координаты игрока границами экрана $0 \le x \le W - w$.
* **Что возвращает:** `void`
* **Зачем используется:** Управляет перемещением игрока и врагов, предотвращая вылет корабля защитника за пределы игрового поля.
* **Пример кода:**
  ```javascript
  move(dx, dy, deltaTime) {
    this.x += dx * this.speed * deltaTime;
    this.y += dy * this.speed * deltaTime;
    this.x = Math.max(0, Math.min(this.canvasWidth - this.width, this.x));
  }
  ```

---

### 2.2 `shoot()`
* **Как работает:** Проверяет таймер перезарядки (cooldown). Если стрельба разрешена, инстанцирует новый объект класса `Bullet` с начальными координатами на носу корабля $(x + \frac{w}{2}, y)$ и добавляет его в общий массив пуль `bullets`.
* **Что возвращает:** `Bullet | null` (экземпляр созданной пули или `null`, если перезарядка ещё не завершилась).
* **Зачем используется:** Реализует механику атаки игрока и вражеских кораблей.
* **Пример кода:**
  ```javascript
  shoot() {
    if (this.cooldown > 0) return null;
    const bullet = new Bullet(this.x + this.width / 2, this.y, -500);
    this.cooldown = 0.15; // 150 мс между выстрелами
    return bullet;
  }
  ```

---

### 2.3 `takeDamage(amount)`
* **Как работает:** Вычитает переданный объем урона `amount` из текущего показателя здоровья $HP$: $HP_{new} = HP - amount$. Если $HP \le 0$, выставляет флаг `isDead = true` и генерирует событие уничтожения.
* **Что возвращает:** `boolean` (`true`, если урон привёл к гибели объекта, и `false`, если объект выжил).
* **Зачем используется:** Управляет расчётом выживаемости игрока и врагов при попадании снарядов или столкновениях.
* **Пример кода:**
  ```javascript
  takeDamage(amount) {
    this.health -= amount;
    if (this.health <= 0) {
      this.health = 0;
      this.destroy();
      return true;
    }
    return false;
  }
  ```

---

### 2.4 `destroy()`
* **Как работает:** Помечает объект флажком `isPendingRemoval = true`, проигрывает звук взрыва и создает массив частиц в точке с координатами объекта $(x, y)$.
* **Что возвращает:** `void`
* **Зачем используется:** Безопасное удаление объекта из игрового мира с вызовом соответствующих визуальных эффектов.
* **Пример кода:**
  ```javascript
  destroy() {
    this.active = false;
    this.createExplosion(this.x + this.width / 2, this.y + this.height / 2);
    this.audio.play('explosion');
  }
  ```

---

## 3. Методы коллизий и генерации (Collisions & Spawning)

### 3.1 `checkCollisions()`
* **Как работает:** Перебирает пары объектов (пули игрока $\leftrightarrow$ враги, корабль игрока $\leftrightarrow$ враги) и вычисляет пересечение их bounding-box'ов или радиусов.
* **Что возвращает:** `void`
* **Зачем используется:** Главный координатор физических взаимодействий в игре.
* **Пример кода:**
  ```javascript
  checkCollisions() {
    this.bullets.forEach(bullet => {
      this.enemies.forEach(enemy => {
        if (this.isColliding(bullet, enemy)) {
          enemy.takeDamage(bullet.damage);
          bullet.active = false;
        }
      });
    });
  }
  ```

---

### 3.2 `isColliding(rectA, rectB)`
* **Как работает:** Реализует алгоритм **AABB** (Axis-Aligned Bounding Box). Проверяет наложение двух прямоугольников по оси $X$ и $Y$:
  $$AABB = (A.x < B.x + B.w) \land (A.x + A.w > B.x) \land (A.y < B.y + B.h) \land (A.y + A.h > B.y)$$
* **Что возвращает:** `boolean` (`true` при наличии перекрытия, `false` при отсутствии).
* **Зачем используется:** Быстрое и вычислительно лёгкое определение факта столкновения двух объектов.
* **Пример кода:**
  ```javascript
  isColliding(a, b) {
    return a.x < b.x + b.width &&
           a.x + a.width > b.x &&
           a.y < b.y + b.height &&
           a.y + a.height > b.y;
  }
  ```

---

### 3.3 `spawnEnemy()`
* **Как работает:** Генерирует случайно выбираемый тип врага (истребитель, астероид, босс) с координатой $x = \text{random}(0, W - w_{enemy})$ и $y = -h_{enemy}$, за пределами верхней границы экрана.
* **Что возвращает:** `Enemy` (созданный экземпляр врага).
* **Зачем используется:** Поддерживает динамику игрового процесса, постепенно заполняя экран противниками по мере времени.
* **Пример кода:**
  ```javascript
  spawnEnemy() {
    const randomX = Math.random() * (this.width - 40);
    const enemy = new Enemy(randomX, -50, this.currentWaveSpeed);
    this.enemies.push(enemy);
    return enemy;
  }
  ```

## 4. Методы работы со структурами данных (Array Methods)

### 4.1 `Array.prototype.filter()`
* **Как работает:** Создаёт новый массив, включив в него только те элементы исходного массива, для которых переданная функция-предикат вернула `true`.
* **Что возвращает:** `Array` (новый отфильтрованный массив).
* **Зачем используется:** Очистка списков объектов от тех, которые улетели за пределы экрана или были уничтожены (garbage collection).
* **Пример кода:**
  ```javascript
  // Удаление пуль, вылетевших за верхний край экрана или уничтоживших цель
  this.bullets = this.bullets.filter(bullet => bullet.y > 0 && bullet.active);
  ```

---

### 4.2 `Array.prototype.forEach()`
* **Как работает:** Выполняет переданную функцию последовательно для каждого элемента массива.
* **Что возвращает:** `undefined`
* **Зачем используется:** Обход всех существующих объектов кадра для последовательного вызова их методов `update()` и `draw()`.
* **Пример кода:**
  ```javascript
  this.particles.forEach(p => p.update(deltaTime));
  ```

---

### 4.3 `Array.prototype.push()`
* **Как работает:** Добавляет один или несколько элементов в конец существующего массива и изменяет его длину.
* **Что возвращает:** `number` (новую длину массива).
* **Зачем используется:** Мгновенное добавление новых пуль, созданных врагов и частиц взрыва в соответствующие списки сцены.
* **Пример кода:**
  ```javascript
  this.bullets.push(new Bullet(x, y));
  ```

---

### 4.4 `Array.prototype.splice()`
* **Как работает:** Изменяет содержимое массива, удаляя существующие элементы по указанному индексу и/или добавляя новые.
* **Что возвращает:** `Array` (массив содержащий удаленные элементы).
* **Зачем используется:** Точечное удаление определённого элемента из массива без создания нового массива.
* **Пример кода:**
  ```javascript
  const index = this.enemies.indexOf(deadEnemy);
  if (index !== -1) {
    this.enemies.splice(index, 1);
  }
  ```

## 5. Графические методы Canvas 2D API

### 5.1 `clearRect(x, y, width, height)`
* **Как работает:** Стирает все пиксели в указанном прямоугольнике, устанавливая их в прозрачный чёрный цвет `rgba(0,0,0,0)`.
* **Что возвращает:** `undefined`
* **Зачем используется:** Очистка экрана перед рисованием нового кадра для предотвращения эффекта «шлейфа» старых объектов.
* **Пример кода:**
  ```javascript
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  ```

---

### 5.2 `drawImage(image, sx, sy, sWidth, sHeight, dx, dy, dWidth, dHeight)`
* **Как работает:** Рисует изображение или спрайт из тайлсета на холсте Canvas. Может производить кадрирование (вырезку области спрайта) и масштабирование.
* **Что возвращает:** `undefined`
* **Зачем используется:** Отображение спрайтов космических кораблей, снарядов, взрывов и фона.
* **Пример кода:**
  ```javascript
  ctx.drawImage(this.spriteSheet, 0, 0, 64, 64, this.x, this.y, 64, 64);
  ```

---

### 5.3 `save()` и `restore()`
* **Как работает:** `save()` сохраняет текущее состояние контекста (трансформации, повороты, прозрачность `globalAlpha`, стили) в стек. `restore()` восстанавливает последнее сохранённое состояние из стека.
* **Что возвращает:** `undefined`
* **Зачем используется:** Изоляция графических трансформаций (например, при повороте корабля или временном изменении прозрачности при получении урона), чтобы они не влияли на отрисовку остальных объектов.
* **Пример кода:**
  ```javascript
  ctx.save();
  ctx.translate(this.x + this.width / 2, this.y + this.height / 2);
  ctx.rotate(this.angle);
  ctx.drawImage(this.image, -this.width / 2, -this.height / 2);
  ctx.restore();
  ```
