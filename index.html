Модуль 1: Подключение DOM, Состояние игры и Параллакс-звёзды

Начинаем файл game.js с получения доступа к холсту HTML5 Canvas (начало координат (0, 0) в левом верхнем углу), всем элементам интерфейса (HUD и экраны меню), объявления переменных состояния игры и генерации 90 мерцающих звёзд параллакс-фона.

Схема 1.1: Система координат HTML5 Canvas и генерация звёздного поля

Разбор методов JS:

document.getElementById(id) & canvas.getContext('2d')

Как работает: Находит HTML-элемент по его уникальному id, а getContext('2d') возвращает «кисть» для рисования 2D-графики на холсте.

Что возвращает: Ссылку на DOM-элемент / объект CanvasRenderingContext2D.

Зачем в игре: Связывает JS с холстом, счётчиком очков, полоской щита и экранами меню.

Array.from({ length: N }, callback)

Как работает: Создаёт массив заданной длины N и заполняет его объектами через функцию обратного вызова.

Что возвращает: Новый массив Array со сформированными элементами.

Зачем в игре: Мгновенная генерация 90 звёзд с индивидуальными X, Y, размером, прозрачностью и скоростью.

ctx.fillRect(x, y, width, height)

Как работает: Закрашивает прямоугольную область на холсте цветом из ctx.fillStyle.

Что возвращает: undefined.

Зачем в игре: Очистка фона цветом #050814 и отрисовка каждой звезды в render().

Модуль 3: Управление, Функция старта и Главный игровой цикл

Настраиваем клавиатуру с защитой от прокрутки страницы (e.preventDefault()) и «залипания» клавиш (blur). Пишем функцию startGame() для запуска/перезапуска игры, а также каркас update(), render() и бесконечный цикл loop().

Разбор методов JS:

e.preventDefault() & element.blur()

Как работает: preventDefault() отменяет стандартную прокрутку браузера по Пробелу/стрелкам, а blur() снимает фокус с нажатой кнопки «Начать бой».

Зачем в игре: Чтобы нажатие Пробела для стрельбы случайно не перезапускало игру и не скроллило страницу.

window.requestAnimationFrame(loop)

Как работает: Запрашивает у браузера вызов функции loop перед следующей перерисовкой экрана (60/144 FPS).

Что возвращает: Числовой идентификатор кадра requestID.

Зачем в игре: Главный двигатель, который непрерывно вызывает update() и render().

Math.max(30, Math.min(canvas.width - 30, player.x))

Как работает: Ограничивает значение player.x в диапазоне от 30 до canvas.width - 30 (приём Clamp).

Зачем в игре: Не даёт кораблю вылететь за левый или правый край холста.

  startBtn.blur();

function update() {
  if (!isRunning || gameOver) return;

  if (keys['ArrowRight'] || keys['KeyD']) player.x += player.speed;

    ctx.fillRect(s.x, s.y, s.size, s.size);
  });
  // Здесь рисуем пули, астероиды, бонусы и корабль из Модуля 2

Модуль 4: Процедурные астероиды в полярных координатах

Наши астероиды — это не банальные кружочки! Фабрика createAsteroid() процедурно строит многоугольник из 8–11 вершин с индивидуальными смещениями offset, а spawnAsteroid() периодически выпускает их сверху экрана.

Схема 4.1: Полярный метод построения нерегулярного многоугольника

Разбор методов JS:

Math.cos(angle) & Math.sin(angle)

Как работает: Возвращают косинус и синус угла в радианах.

Что возвращает: number в диапазоне [-1, 1].

Зачем в игре: Перевод полярных координат (угол + радиус) в декартовы координаты вершин (X, Y).

ctx.translate(x, y) & ctx.rotate(angle)

Как работает: Сдвигают центр координат в точку астероида и поворачивают холст на угол ast.angle.

Что возвращает: undefined.

Зачем в игре: Плавное вращение каждого астероида вокруг собственной оси.

// Фабрика астероидов (используется и для спавна, и для осколков)
function createAsteroid(x, y, radius, speed) {
  const points = 8 + Math.floor(Math.random() * 4);
  const offset = [];
  for (let i = 0; i < points; i++) {
    offset.push(radius + (Math.random() * (radius * 0.35) - radius * 0.175));
  }
  return {
    x, y, radius, points, offset,
    speed: speed || Math.random() * 2.2 + 1.6,
    angle: 0,
    rotSpeed: Math.random() * 0.04 - 0.02
  };
}

function spawnAsteroid() {
  const radius = Math.random() > 0.45 ? 36 : 22;
  const x = Math.random() * (canvas.width - 80) + 40;
  asteroids.push(createAsteroid(x, -50, radius));
}

// Внутри update() добавляем случайный спавн:
if (Math.random() < 0.028) spawnAsteroid();

// Внутри render() отрисовываем все астероиды:
ctx.shadowBlur = 0;
asteroids.forEach(ast => {
  ctx.save();
  ctx.translate(ast.x, ast.y);
  ctx.rotate(ast.angle);
  ctx.beginPath();
  for (let i = 0; i < ast.points; i++) {
    const a = (i / ast.points) * Math.PI * 2;
    const r = ast.offset[i];
    if (i === 0) ctx.moveTo(Math.cos(a) * r, Math.sin(a) * r);
    else ctx.lineTo(Math.cos(a) * r, Math.sin(a) * r);
  }
  ctx.closePath();
  ctx.fillStyle = '#161e31';
  ctx.fill();
  ctx.strokeStyle = '#8fa3bf';
  ctx.lineWidth = 2;
  ctx.stroke();
  ctx.restore();
});

Модуль 5: Стрельба, Коллизии и Раскалывание Астероидов

Добавляем функцию стрельбы shoot() (одинарный и тройной режимы) с перезарядкой 140 мс через Date.now(). Столкновения пуль с астероидами и астероидов с кораблём проверяются по формуле Евклида Math.hypot(). Крупные астероиды (radius > 26) раскалываются на 2 осколка.

Схема 5.1: Условие столкновения: hypot(dx, dy) < R1 + R2

Разбор методов JS:

Math.hypot(dx, dy)

Как работает: Вычисляет расстояние между двумя точками по теореме Пифагора.

Что возвращает: number (расстояние в пикселях).

Зачем в игре: Проверка попадания лазеров в астероид, ударов по кораблю и подбора бонусов.

Date.now() & Array.prototype.splice(index, 1)

Как работает: Date.now() даёт текущее время в миллисекундах (для скорострельности), а splice() в обратном цикле for безопасно удаляет уничтоженный объект.

Зачем в игре: Ограничение темпа стрельбы и точное удаление столкнувшихся пуль и астероидов.

function shoot() {
  playSound('laser');
  if (laserMode === 'SINGLE') {
    bullets.push({ x: player.x, y: player.y - 24, vx: 0, vy: -11 });
  } else {
    bullets.push({ x: player.x - 12, y: player.y - 18, vx: -2.2, vy: -10 });
    bullets.push({ x: player.x, y: player.y - 24, vx: 0, vy: -11 });
    bullets.push({ x: player.x + 12, y: player.y - 18, vx: 2.2, vy: -10 });
  }
}

// Внутри update(): стрельба и движение пуль
if (keys['Space'] && Date.now() - lastShot > 140) {
  shoot();
  lastShot = Date.now();
}
bullets.forEach(b => { b.x += b.vx; b.y += b.vy; });
bullets = bullets.filter(b => b.y > -20);

// Внутри update(): движение астероидов и столкновение с кораблём
for (let i = asteroids.length - 1; i >= 0; i--) {
  const ast = asteroids[i];
  ast.y += ast.speed;
  ast.angle += ast.rotSpeed;

  if (Math.hypot(ast.x - player.x, ast.y - player.y) < ast.radius + 16) {
    shield = Math.max(0, shield - 25);
    shakeTime = 14;
    playSound('explode');

    asteroids.splice(i, 1);

      gameOver = true;
      finalScoreEl.innerText = score;
      finalRecordEl.innerText = saveAndGetRecord(score);
      gameOverScreen.classList.remove('hidden');
    }
    continue;
  }
  if (ast.y > canvas.height + 60) asteroids.splice(i, 1);
}

// Внутри update(): столкновения пуль с астероидами и раскол
for (let bIdx = bullets.length - 1; bIdx >= 0; bIdx--) {
  const b = bullets[bIdx];
  for (let aIdx = asteroids.length - 1; aIdx >= 0; aIdx--) {
    const ast = asteroids[aIdx];
    if (Math.hypot(b.x - ast.x, b.y - ast.y) < ast.radius + 5) {
      playSound('explode');
      createExplosion(ast.x, ast.y, '#8fa3bf', 8);

      if (Math.random() < 0.28) {
        bonuses.push({ x: ast.x, y: ast.y, type: Math.random() > 0.5 ? 'TRIPLE' : 'SHIELD' });
      }
      if (ast.radius > 26) {
        asteroids.push(createAsteroid(ast.x - 14, ast.y, 18, ast.speed + 0.6));
        asteroids.push(createAsteroid(ast.x + 14, ast.y, 18, ast.speed + 0.6));
      }
      asteroids.splice(aIdx, 1);
      bullets.splice(bIdx, 1);
      score += 100;
      break;
    }
  }
}

// Внутри render(): отрисовка неоновых пуль
ctx.shadowBlur = 12;
ctx.shadowColor = '#00f3ff';
ctx.fillStyle = '#00f3ff';
bullets.forEach(b => ctx.fillRect(b.x - 2, b.y - 10, 4, 14));

Модуль 7: Процедурный Звук Web Audio API и Рекорды в localStorage

Игра обходится без сторонних .mp3 файлов! Функция playSound(type) синтезирует звуки лазера (sawtooth), взрыва (square) и бонуса (sine) на одном общем AudioContext, а saveAndGetRecord() надёжно хранит рекорд в localStorage.

Разбор методов JS:

new AudioContext() & createOscillator()

Как работает: Создаёт звуковой узел-генератор волны и плавно меняет её частоту через exponentialRampToValueAtTime().

Важно: Создаём audioCtx один раз и переиспользуем его, чтобы не упереться в лимит браузера (6 контекстов).

localStorage.setItem(key, val) / getItem(key)

Как работает: Сохраняет и читает пары ключ-значение в памяти браузера. Обёрнуто в try / catch на случай ограничений приватного режима.

Зачем в игре: Запоминает лучший рекорд игрока между запусками.

// Безопасное сохранение и чтение рекорда
function saveAndGetRecord(currentScore) {
  try {
    const prev = parseInt(localStorage.getItem('star_defender_highscore') || '0', 10);
    const best = Math.max(currentScore, isNaN(prev) ? 0 : prev);
    localStorage.setItem('star_defender_highscore', String(best));
    return best;
  } catch (e) {
    return currentScore;
  }
}

// Звуковой синтезатор Web Audio API (лазер, взрыв, бонус)
function playSound(type) {
  try {
    const AudioCtx = window.AudioContext || window.webkitAudioContext;
    if (!AudioCtx) return;

// Безопасная работа с localStorage
function saveAndGetRecord(currentScore) {
  try {
    const prev = parseInt(localStorage.getItem('star_defender_highscore') || '0', 10);
    const best = Math.max(currentScore, isNaN(prev) ? 0 : prev);
    localStorage.setItem('star_defender_highscore', String(best));
    return best;
  } catch (e) {
    return currentScore;
  }
}

// Звуковой синтезатор Web Audio API (с переиспользованием одного AudioContext)
function playSound(type) {
  try {
    const AudioCtx = window.AudioContext || window.webkitAudioContext;
    if (!AudioCtx) return;
    if (!audioCtx) audioCtx = new AudioCtx();
    if (audioCtx.state === 'suspended') audioCtx.resume();

    const osc = audioCtx.createOscillator();
    const gain = audioCtx.createGain();
    osc.connect(gain);
    gain.connect(audioCtx.destination);

    const now = audioCtx.currentTime;
    if (type === 'laser') {
      osc.type = 'sawtooth';
      osc.frequency.setValueAtTime(800, now);
      osc.frequency.exponentialRampToValueAtTime(180, now + 0.1);
      gain.gain.setValueAtTime(0.12, now);
      gain.gain.exponentialRampToValueAtTime(0.001, now + 0.1);
      osc.start(now);
      osc.stop(now + 0.1);
    } else if (type === 'explode') {
      osc.type = 'square';
      osc.frequency.setValueAtTime(140, now);
      osc.frequency.exponentialRampToValueAtTime(35, now + 0.22);
      gain.gain.setValueAtTime(0.18, now);
      gain.gain.exponentialRampToValueAtTime(0.001, now + 0.22);
      osc.start(now);
      osc.stop(now + 0.22);
    } else if (type === 'bonus') {
      osc.type = 'sine';
      osc.frequency.setValueAtTime(400, now);
      osc.frequency.exponentialRampToValueAtTime(900, now + 0.18);
      gain.gain.setValueAtTime(0.15, now);
      gain.gain.exponentialRampToValueAtTime(0.001, now + 0.18);
      osc.start(now);
      osc.stop(now + 0.18);
    }
  } catch (e) {}
}

// Фабрика процедурных астероидов (используется и для спавна, и для осколков)
function createAsteroid(x, y, radius, speed) {
  const points = 8 + Math.floor(Math.random() * 4);
  const offset = [];
  for (let i = 0; i < points; i++) {
    offset.push(radius + (Math.random() * (radius * 0.35) - radius * 0.175));
  }
  return {
    x, y, radius, points, offset,
    speed: speed || Math.random() * 2.2 + 1.6,
    angle: 0,
    rotSpeed: Math.random() * 0.04 - 0.02
  };
}

function spawnAsteroid() {
  const radius = Math.random() > 0.45 ? 36 : 22;
  const x = Math.random() * (canvas.width - 80) + 40;
  asteroids.push(createAsteroid(x, -50, radius));
}

function createExplosion(x, y, color = '#8fa3bf', count = 8) {
  for (let i = 0; i < count; i++) {
    particles.push({
      x, y,
      vx: (Math.random() - 0.5) * 6,
      vy: (Math.random() - 0.5) * 6,
      life: 1,
      color
    });
  }
}

function shoot() {
  playSound('laser');
  if (laserMode === 'SINGLE') {
    bullets.push({ x: player.x, y: player.y - 24, vx: 0, vy: -11 });
  } else {
    bullets.push({ x: player.x - 12, y: player.y - 18, vx: -2.2, vy: -10 });
    bullets.push({ x: player.x, y: player.y - 24, vx: 0, vy: -11 });
    bullets.push({ x: player.x + 12, y: player.y - 18, vx: 2.2, vy: -10 });
  }
}

function startGame() {
  score = 0;

  laserTimer = 0;

function update() {
  if (!isRunning || gameOver) return;

  // Движение корабля
  if (keys['ArrowLeft'] || keys['KeyA']) player.x -= player.speed;
  if (keys['ArrowRight'] || keys['KeyD']) player.x += player.speed;
  player.x = Math.max(30, Math.min(canvas.width - 30, player.x));

  // Стрельба
  if (keys['Space'] && Date.now() - lastShot > 140) {
    shoot();
    lastShot = Date.now();
  }

  // Таймер тройного лазера
  if (laserTimer > 0) {
    laserTimer--;
    if (laserTimer === 0) {
      laserMode = 'SINGLE';
      laserModeEl.innerText = 'ОДИНАРНЫЙ';
    }
  }

  // Звёзды
  stars.forEach(s => {
    s.y += s.speed;
    if (s.y > canvas.height) s.y = 0;
  });

  // Пули
  bullets.forEach(b => { b.x += b.vx; b.y += b.vy; });
  bullets = bullets.filter(b => b.y > -20);

  // Спавн астероидов
  if (Math.random() < 0.028) spawnAsteroid();

  // Обновление астероидов и столкновение с игроком
  for (let i = asteroids.length - 1; i >= 0; i--) {
    const ast = asteroids[i];
    ast.y += ast.speed;
    ast.angle += ast.rotSpeed;

    if (Math.hypot(ast.x - player.x, ast.y - player.y) < ast.radius + 16) {
      shield = Math.max(0, shield - 25);
      shakeTime = 14;
      playSound('explode');
      createExplosion(ast.x, ast.y, '#ff007f', 12);
      asteroids.splice(i, 1);

      if (shield <= 0) {
        gameOver = true;
        finalScoreEl.innerText = score;
        finalRecordEl.innerText = saveAndGetRecord(score);
        gameOverScreen.classList.remove('hidden');
      }
      continue;
    }

    if (ast.y > canvas.height + 60) {
      asteroids.splice(i, 1);
    }
  }

  // Столкновения пуль с астероидами
  for (let bIdx = bullets.length - 1; bIdx >= 0; bIdx--) {
    const b = bullets[bIdx];
    for (let aIdx = asteroids.length - 1; aIdx >= 0; aIdx--) {
      const ast = asteroids[aIdx];
      if (Math.hypot(b.x - ast.x, b.y - ast.y) < ast.radius + 5) {
        playSound('explode');
        createExplosion(ast.x, ast.y, '#8fa3bf', 8);

        // Шанс выпадения бонуса
        if (Math.random() < 0.28) {
          bonuses.push({
            x: ast.x, y: ast.y,
            type: Math.random() > 0.5 ? 'TRIPLE' : 'SHIELD'
          });
        }

        // Раскалывание крупного астероида на 2 осколка
        if (ast.radius > 26) {
          asteroids.push(createAsteroid(ast.x - 14, ast.y, 18, ast.speed + 0.6));
          asteroids.push(createAsteroid(ast.x + 14, ast.y, 18, ast.speed + 0.6));
        }

        asteroids.splice(aIdx, 1);
        bullets.splice(bIdx, 1);
        score += 100;
        break;
      }
    }
  }

  // Частицы
  particles.forEach(p => {
    p.x += p.vx;
    p.y += p.vy;
    p.life -= 0.04;
  });
  particles = particles.filter(p => p.life > 0);

  // Бонусы
  for (let idx = bonuses.length - 1; idx >= 0; idx--) {
    const bn = bonuses[idx];
    bn.y += 2.2;
    if (Math.hypot(bn.x - player.x, bn.y - player.y) < 26) {
      playSound('bonus');
      if (bn.type === 'TRIPLE') {
        laserMode = 'TRIPLE';
        laserTimer = 320;
        laserModeEl.innerText = 'ТРОЙНОЙ';
      } else {
        shield = Math.min(100, shield + 30);
      }
      bonuses.splice(idx, 1);
    } else if (bn.y > canvas.height + 20) {
      bonuses.splice(idx, 1);
    }
  }

  // Обновление HUD
  scoreEl.innerText = score;
  shieldBarEl.style.width = shield + '%';
}

function render() {
  ctx.save();
  if (shakeTime > 0) {
    ctx.translate((Math.random() - 0.5) * 8, (Math.random() - 0.5) * 8);
    shakeTime--;
  }

  ctx.fillStyle = '#050814';
  ctx.fillRect(0, 0, canvas.width, canvas.height);

  // Отрисовка звёзд
  stars.forEach(s => {
    ctx.fillStyle = `rgba(255, 255, 255, ${s.alpha})`;
    ctx.fillRect(s.x, s.y, s.size, s.size);
  });

  // Отрисовка частиц взрыва
  particles.forEach(p => {
    ctx.globalAlpha = p.life;
    ctx.fillStyle = p.color;
    ctx.fillRect(p.x, p.y, 3, 3);
  });
  ctx.globalAlpha = 1.0;

  // Отрисовка пуль
  ctx.shadowBlur = 12;
  ctx.shadowColor = '#00f3ff';
  ctx.fillStyle = '#00f3ff';
  bullets.forEach(b => ctx.fillRect(b.x - 2, b.y - 10, 4, 14));

  // Отрисовка астероидов
  ctx.shadowBlur = 0;
  asteroids.forEach(ast => {
    ctx.save();
    ctx.translate(ast.x, ast.y);
    ctx.rotate(ast.angle);
    ctx.beginPath();
    for (let i = 0; i < ast.points; i++) {
      const a = (i / ast.points) * Math.PI * 2;
      const r = ast.offset[i];
      if (i === 0) ctx.moveTo(Math.cos(a) * r, Math.sin(a) * r);
      else ctx.lineTo(Math.cos(a) * r, Math.sin(a) * r);
    }
    ctx.closePath();
    ctx.fillStyle = '#161e31';
    ctx.fill();
    ctx.strokeStyle = '#8fa3bf';
    ctx.lineWidth = 2;
    ctx.stroke();
    ctx.restore();
  });

  // Отрисовка бонусов
  bonuses.forEach(bn => {
    ctx.save();
    ctx.shadowBlur = 10;
    ctx.shadowColor = bn.type === 'TRIPLE' ? '#f59e0b' : '#10b981';
    ctx.beginPath();
    ctx.arc(bn.x, bn.y, 11, 0, Math.PI * 2);
    ctx.fillStyle = bn.type === 'TRIPLE' ? '#f59e0b' : '#10b981';
    ctx.fill();
    ctx.restore();
  });

  // Отрисовка корабля игрока
  ctx.save();
  ctx.shadowBlur = 16;
  ctx.shadowColor = '#00f3ff';
  ctx.beginPath();
  ctx.moveTo(player.x, player.y - 24);
  ctx.lineTo(player.x + 22, player.y + 18);
  ctx.lineTo(player.x, player.y + 10);
  ctx.lineTo(player.x - 22, player.y + 18);
  ctx.closePath();
  ctx.fillStyle = '#0b0f19';
  ctx.fill();
  ctx.strokeStyle = '#00f3ff';
  ctx.lineWidth = 2.5;
  ctx.stroke();

  // Кокпит
  ctx.beginPath();
  ctx.ellipse(player.x, player.y - 4, 6, 12, 0, 0, Math.PI * 2);
  ctx.fillStyle = '#ffffff';
  ctx.fill();

  // Пламя двигателя
  ctx.shadowColor = '#ff007f';
  ctx.beginPath();
  ctx.moveTo(player.x - 6, player.y + 12);
  ctx.lineTo(player.x, player.y + 24 + Math.random() * 7);
  ctx.lineTo(player.x + 6, player.y + 12);
  ctx.fillStyle = '#ff007f';
  ctx.fill();
  ctx.restore();

  ctx.restore();
}

function loop() {
  update();
  render();
  requestAnimationFrame(loop);
}

startBtn.addEventListener('click', startGame);
restartBtn.addEventListener('click', startGame);
requestAnimationFrame(loop);
