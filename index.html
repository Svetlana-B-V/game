Модуль 1: Архитектура, HTML5 Canvas и Параллакс-звёзды

На первом этапе создаётся координатная плоскость HTML5 Canvas $(0,0 \text{ слева вверху})$ и инициализируется многослойный параллакс-фон с мерцающими звёздами различной глубины.

Схема 1.1: Система координат HTML5 Canvas и генерация звёздного поля

Разбор методов JS:

Array.from({ length: N }, callback)

Как работает: Создаёт массив заданной длины $N$ и заполняет его объектами через функцию обратного вызова.

Что возвращает: Новый массивы `Array` со сформированными элементами.

Зачем в игре: Мгновенная генерация 100+ звёзд с индивидуальным $X, Y$, радиусом и скоростью.

ctx.fillRect(x, y, width, height)

Как работает: Закрашивает прямоугольную область на холсте цветом из `ctx.fillStyle`.

Что возвращает: `undefined`.

Зачем в игре: Полная очистка фона темным оттенком `#050814` перед вычислением нового кадра.

// Инициализация звездного параллакса
const stars = Array.from({ length: 80 }, () => ({
  x: Math.random() * canvas.width,
  y: Math.random() * canvas.height,
  size: Math.random() * 2 + 0.5,
  speed: Math.random() * 1.5 + 0.5,
  alpha: Math.random()
}));

function drawStars() {
  stars.forEach(star => {
    ctx.fillStyle = `rgba(255, 255, 255, ${star.alpha})`;
    ctx.fillRect(star.x, star.y, star.size, star.size);
    star.y += star.speed;
    if (star.y > canvas.height) star.y = 0;
  });
}

Модуль 2: Детализированный векторный корабль с неоновым свечением

Корабль игрока отрисовывается без использования растровых спрайтов — применяются векторные пути `beginPath()`, овальный кокпит `ellipse()`, неоновый свет `shadowBlur` и пульсирующее малиновое пламя двигателя.

Схема 2.1: Геометрические точки и пути отрисовки боевого челнока

Разбор методов JS:

ctx.beginPath() / moveTo() / lineTo()

Как работает: Открывает новый векторный путь, перемещает пера к начальной точке и вычерчивает отрезки.

Что возвращает: `undefined`.

Зачем в игре: Формирование корпуса корабля с хищными заостренными крыльями.

ctx.ellipse(x, y, radiusX, radiusY, rotation, startAngle, endAngle)

Как работает: Рисует эллиптическую дугу по центру и двум радиусам.

Что возвращает: `undefined`.

Зачем в игре: Отрисовка белого каплевидного фонаря кабины пилота (кокпита).

ctx.shadowBlur & ctx.shadowColor

Как работает: Настраивает параметры свечения (Гауссово размытие) для последующих strokes & fills.

Что возвращает: Свойства контекста Canvas.

Зачем в игре: Реализация сочного неонового киберпанк-свечения элементов.

function drawPlayer(x, y) {
  ctx.save();
  // Неоновое свечение
  ctx.shadowBlur = 15;
  ctx.shadowColor = '#00f3ff';
  
  // Корпус корабля
  ctx.beginPath();
  ctx.moveTo(x, y - 22);
  ctx.lineTo(x + 20, y + 18);
  ctx.lineTo(x, y + 10);
  ctx.lineTo(x - 20, y + 18);
  ctx.closePath();
  ctx.fillStyle = '#0b0f19';
  ctx.fill();
  ctx.strokeStyle = '#00f3ff';
  ctx.lineWidth = 2;
  ctx.stroke();

  // Овальный кокпит
  ctx.beginPath();
  ctx.ellipse(x, y - 4, 5, 10, 0, 0, Math.PI * 2);
  ctx.fillStyle = '#ffffff';
  ctx.fill();

  // Пламя двигателя
  ctx.shadowColor = '#ff007f';
  ctx.beginPath();
  ctx.moveTo(x - 6, y + 12);
  ctx.lineTo(x, y + 22 + Math.random() * 6);
  ctx.lineTo(x + 6, y + 12);
  ctx.fillStyle = '#ff007f';
  ctx.fill();

  ctx.restore();
}

Модуль 3: Игровой цикл и расчёт ограничений позиционирования

Игровой цикл синхронизируется с частотой развертки монитора через `requestAnimationFrame()`. Управление обрабатывается объектом зажатых клавиш (`keys`), а положение корабля ограничивается с помощью `Math.max` и `Math.min`.

Разбор методов JS:

window.requestAnimationFrame(callback)

Как работает: Запрашивает у браузера вызов функции обновления графики перед следующей перерисовкой экрана (~60/144 FPS).

Что возвращает: Идентификатор таймера `requestID` (число).

Зачем в игре: Главная пружина плавного бесшовного игрового цикла без лагов.

Math.max(a, b) & Math.min(a, b)

Как работает: Возвращают наибольшее и наименьшее значение среди аргументов.

Что возвращает: `number` (число).

Зачем в игре: Ограничение $X$-координаты игрока (Clamp), не позволяющее вылететь за рамки Canvas.

const keys = {};
window.addEventListener('keydown', e => keys[e.code] = true);
window.addEventListener('keyup', e => keys[e.code] = false);

function updatePlayer() {
  if (keys['ArrowLeft'] || keys['KeyA']) player.x -= player.speed;
  if (keys['ArrowRight'] || keys['KeyD']) player.x += player.speed;

  // Жесткое ограничение в пределах рамки
  player.x = Math.max(25, Math.min(canvas.width - 25, player.x));
}

Модуль 4: Процедурные астероиды в полярных координатах

Наши астероиды — это НЕ банальные кружочки! Они процедурно строятся из 7–11 вершин через полярные координаты: $x = r \cdot \cos(\theta)$, $y = r \cdot \sin(\theta)$ с варьируемым радиусом.

Схема 4.1: Полярный метод построения нерегулярного многоугольника

Разбор методов JS:

Math.cos(angle) & Math.sin(angle)

Как работает: Возвращают косинус и синус угла в радианах.

Что возвращает: `number` $[-1, 1]$.

Зачем в игре: Перевод полярных координат (угол + радиус) в декартовы координаты холста $(X, Y)$.

ctx.translate(x, y) & ctx.rotate(angle)

Как работает: Сдвигают матрицу трансформации в центр астероида и поворачивают холст.

Что возвращает: `undefined`.

Зачем в игре: Плавное естественное вращение каждого астероида вокруг собственной оси.

function createAsteroid(x, y, radius) {
  const pointsCount = 9;
  const offset = [];
  for (let i = 0; i < pointsCount; i++) {
    offset.push(radius + (Math.random() * 12 - 6));
  }
  return { x, y, radius, pointsCount, offset, angle: 0, rotSpeed: Math.random() * 0.04 - 0.02 };
}

function drawAsteroid(ast) {
  ctx.save();
  ctx.translate(ast.x, ast.y);
  ctx.rotate(ast.angle);
  ctx.beginPath();
  for (let i = 0; i < ast.pointsCount; i++) {
    const a = (i / ast.pointsCount) * Math.PI * 2;
    const r = ast.offset[i];
    const px = Math.cos(a) * r;
    const py = Math.sin(a) * r;
    if (i === 0) ctx.moveTo(px, py);
    else ctx.lineTo(px, py);
  }
  ctx.closePath();
  ctx.fillStyle = '#161e31';
  ctx.fill();
  ctx.strokeStyle = '#8fa3bf';
  ctx.lineWidth = 2;
  ctx.stroke();
  ctx.restore();
}

Модуль 5: Стрельба, Коллизии и Раскалывание Астероидов

Расчёт точности попаданий снарядов выполняется по формуле расстояния Евклида `Math.hypot()`. Крупные астероиды не пропадают бесследно, а разлетаются на 2 меньших осколка через `splice()` и `push()`.

Схема 5.1: Условие столкновения: hypot(dx, dy) < R1 + R2

Разбор методов JS:

Math.hypot(dx, dy)

Как работает: Вычисляет квадратный корень из суммы квадратов аргументов $\sqrt{dx^2 + dy^2}$.

Что возвращает: `number` (расстояние между объектами).

Зачем в игре: Самая быстрая проверка пересечения окружностей астероидов и пуль.

Array.prototype.filter(predicate)

Как работает: Фильтрует элементы массива, оставляя только вернувшие `true`.

Что возвращает: Новый отфильтрованный массив.

Зачем в игре: Удаление вылетевших за рамки экрана лазеров и уничтоженных тел.

function checkCollisions() {
  bullets.forEach((b, bIdx) => {
    asteroids.forEach((ast, aIdx) => {
      const dist = Math.hypot(b.x - ast.x, b.y - ast.y);
      if (dist < ast.radius + 4) {
        // Спавн 2 осколков, если астероид крупный
        if (ast.radius > 20) {
          asteroids.push(createAsteroid(ast.x - 10, ast.y, ast.radius / 2));
          asteroids.push(createAsteroid(ast.x + 10, ast.y, ast.radius / 2));
        }
        asteroids.splice(aIdx, 1);
        bullets.splice(bIdx, 1);
        score += 100;
      }
    });
  });
}

Модуль 6: Выпадающие Бонусы, Частицы и Screen Shake

Из астероидов выпадают бонусы: **Тройной Лазер** (янтарная сфера) и **Ремонт Щита** (зелёная сфера). При попаданиях генерируются угасающие искры через `globalAlpha`, а при уроне экран сотрясается с помощью случайного смещения матрицы `ctx.translate`.

Разбор методов JS:

ctx.globalAlpha

Как работает: Устанавливает степень прозрачности $[0.0, 1.0]$ для всех последующих графических вызовов.

Что возвращает: Значение прозрачности.

Зачем в игре: Плавное растворение искр взрыва перед их полным удалением.

// Эффект тряски экрана (Screen Shake)
let shakeTime = 0;
function triggerShake(duration = 10) { shakeTime = duration; }

function applyScreenShake() {
  if (shakeTime > 0) {
    const offsetX = (Math.random() - 0.5) * 8;
    const offsetY = (Math.random() - 0.5) * 8;
    ctx.translate(offsetX, offsetY);
    shakeTime--;
  }
}

Модуль 7: Процедурный Звук Web Audio API и localStorage

Игра обходится без сторонних `.mp3` файлов! Звуки выстрелов и взрывов генерируются в реальном времени веб-синтезатором Web Audio API. Рекорды сохраняются в память браузера через `localStorage`.

Разбор методов JS:

new AudioContext() & createOscillator()

Как работает: Инициализирует узлы звукового графа браузера и генерирует звуковую волну задаваемой частоты.

Что возвращает: Звуковой контекст и осциллятор.

Зачем в игре: Создание процедурного звука лазера без внешней загрузки файлов.

localStorage.setItem(key, val) / getItem(key)

Как работает: Сохраняет и читает пары ключ-значение в энергонезависимой памяти браузера.

Что возвращает: Строку или `null`.

Зачем в игре: Сохранение наивысшего рекорда очков игрока даже после закрытия вкладки.

// Процедурный синтез звука выстрела
function playLaserSound() {
  if (!soundEnabled) return;
  const audioCtx = new (window.AudioContext || window.webkitAudioContext)();
  const osc = audioCtx.createOscillator();
  const gain = audioCtx.createGain();
  
  osc.type = 'sawtooth';
  osc.frequency.setValueAtTime(800, audioCtx.currentTime);
  osc.frequency.exponentialRampToValueAtTime(150, audioCtx.currentTime + 0.12);
  
  gain.gain.setValueAtTime(0.15, audioCtx.currentTime);
  gain.gain.linearRampToValueAtTime(0.01, audioCtx.currentTime + 0.12);
  
  osc.connect(gain);
  gain.connect(audioCtx.destination);
  
  osc.start();
  osc.stop(audioCtx.currentTime + 0.12);
}

  }

  // Звёзды
  stars.forEach(s => { s.y += s.speed; if (s.y > canvas.height) s.y = 0; });

  // Пули
  bullets.forEach(b => { b.x += b.vx; b.y += b.vy; });
  bullets = bullets.filter(b => b.y > 0);

  // Спавн астероидов
  if (Math.random() < 0.025) spawnAsteroid();

  // Обновление астероидов
  asteroids.forEach(ast => {
    ast.y += ast.speed;
    ast.angle += ast.rotSpeed;

    // Столкновение с игроком
    if (Math.hypot(ast.x - player.x, ast.y - player.y) < ast.radius + 15) {
      shield -= 25;
      shakeTime = 12;
      playSound('explode');
      ast.y = canvas.height + 100;
      if (shield <= 0) {
        gameOver = true;
        document.getElementById('gameOverScreen').classList.remove('hidden');
      }
    }
  });

  // Столкновения Пуля-Астероид
  bullets.forEach((b, bIdx) => {
    asteroids.forEach((ast, aIdx) => {
      if (Math.hypot(b.x - ast.x, b.y - ast.y) < ast.radius + 4) {
        playSound('explode');
        // Шанс бонуса
        if (Math.random() < 0.25) {
          bonuses.push({ x: ast.x, y: ast.y, type: Math.random() > 0.5 ? 'TRIPLE' : 'SHIELD' });
        }
        // Раскалывание
        if (ast.radius > 25) {
          asteroids.push({ ...ast, radius: 18, x: ast.x - 12, speed: ast.speed + 0.5 });
          asteroids.push({ ...ast, radius: 18, x: ast.x + 12, speed: ast.speed + 0.5 });
        }
        asteroids.splice(aIdx, 1);
        bullets.splice(bIdx, 1);
        score += 100;
      }
    });
  });

  // Бонусы
  bonuses.forEach((bn, idx) => {
    bn.y += 2;
    if (Math.hypot(bn.x - player.x, bn.y - player.y) < 25) {
      if (bn.type === 'TRIPLE') {
        laserMode = 'ТРОЙНОЙ';
        laserTimer = 300;
        document.getElementById('hud-laser').innerText = 'ТРОЙНОЙ';
      } else {
        shield = Math.min(100, shield + 30);
      }
      bonuses.splice(idx, 1);
    }
  });

  // Обновление HUD
  document.getElementById('hud-score').innerText = score;
  document.getElementById('hud-shield-bar').style.width = shield + '%';
}

function render() {
  ctx.save();
  if (shakeTime > 0) {
    ctx.translate((Math.random() - 0.5) * 6, (Math.random() - 0.5) * 6);
    shakeTime--;
  }

  ctx.fillStyle = '#050814';
  ctx.fillRect(0, 0, canvas.width, canvas.height);

  // Отрисовка звезд
  ctx.fillStyle = '#ffffff';
  stars.forEach(s => ctx.fillRect(s.x, s.y, s.size, s.size));

  // Отрисовка пуль
  ctx.shadowBlur = 10; ctx.shadowColor = '#00f3ff';
  ctx.fillStyle = '#00f3ff';
  bullets.forEach(b => ctx.fillRect(b.x - 2, b.y - 8, 4, 12));

  // Отрисовка астероидов
  ctx.shadowBlur = 0;
  asteroids.forEach(ast => {
    ctx.save();
    ctx.translate(ast.x, ast.y);
    ctx.rotate(ast.angle);
    ctx.beginPath();
    for (let i = 0; i < ast.points; i++) {
      const a = (i / ast.points) * Math.PI * 2;
      const r = ast.offset[i];
      if (i === 0) ctx.moveTo(Math.cos(a)*r, Math.sin(a)*r);
      else ctx.lineTo(Math.cos(a)*r, Math.sin(a)*r);
    }
    ctx.closePath();
    ctx.fillStyle = '#161e31'; ctx.fill();
    ctx.strokeStyle = '#8fa3bf'; ctx.lineWidth = 2; ctx.stroke();
    ctx.restore();
  });

  // Отрисовка бонусов
  bonuses.forEach(bn => {
    ctx.beginPath();
    ctx.arc(bn.x, bn.y, 10, 0, Math.PI * 2);
    ctx.fillStyle = bn.type === 'TRIPLE' ? '#f59e0b' : '#10b981';
    ctx.fill();
  });

  // Отрисовка Корабля
  ctx.save();
  ctx.shadowBlur = 15; ctx.shadowColor = '#00f3ff';
  ctx.beginPath();
  ctx.moveTo(player.x, player.y - 22);
  ctx.lineTo(player.x + 20, player.y + 18);
  ctx.lineTo(player.x, player.y + 10);
  ctx.lineTo(player.x - 20, player.y + 18);
  ctx.closePath();
  ctx.fillStyle = '#0b0f19'; ctx.fill();
  ctx.strokeStyle = '#00f3ff'; ctx.lineWidth = 2; ctx.stroke();

  // Кокпит
  ctx.beginPath();
  ctx.ellipse(player.x, player.y - 4, 5, 10, 0, 0, Math.PI * 2);
  ctx.fillStyle = '#ffffff'; ctx.fill();

  // Пламя
  ctx.shadowColor = '#ff007f';
  ctx.beginPath();
  ctx.moveTo(player.x - 6, player.y + 12);
  ctx.lineTo(player.x, player.y + 22 + Math.random()*6);
  ctx.lineTo(player.x + 6, player.y + 12);
  ctx.fillStyle = '#ff007f'; ctx.fill();
  ctx.restore();

  ctx.restore();
}

function loop() {
  update();
  render();
  requestAnimationFrame(loop);
}

document.getElementById('startBtn').onclick = () => {
  document.getElementById('startScreen').classList.add('hidden');
  isRunning = true;
};
requestAnimationFrame(loop);
